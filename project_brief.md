# My agent: ai-dev-team
One-liner: A conversational agent that orchestrates a virtual software development team (PM, Designer, Developer, QA, Analyst) to plan, design, code, and evaluate software projects with a catalog of tasks, specifications, and UI design assets.

Tool coverage:
- Memory: Remembers project goals, preferred tech stacks, architectural guidelines, brand color palettes, and team conventions across sessions.
- Tools: Task management (create, assign, and update status of sprint tasks), code verification, design mockup generation, and requirement analysis.
- Catalog/UI: Firestore collection of project tasks (`tasks`) and role deliverables rendered as A2UI cards and tables.
- Image gen: UI/UX mockups, app screen wireframes, and conceptual interface visuals generated by the Designer role and stored in Cloud Storage.
- Sandbox: Python code execution and unit test verification in Agent Engine Sandbox by the Developer & QA roles.

Recommended for every project: memory (Memory Bank), storage (Firestore + Cloud Storage), tools, image generation (gemini-3.1-flash-lite-image), A2UI (v0.8 cards/tables)
Agent-specific / stretch: Agent Platform Code Sandbox for developer code execution, Cloud Trace for tracing multi-role orchestration.
